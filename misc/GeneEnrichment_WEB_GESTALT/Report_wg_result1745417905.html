  • Enrichment method: ORA

  • The interesting list contains 169 user IDs in which 169 user IDs are unambiguously mapped to 169 unique entrezgene IDs and 0 user IDs can not be mapped to any entrezgene ID.
  • The GO Slim summary are based upon the 169 unique entrezgene IDs.

Parameters for the enrichment analysis:

  • Minimum number of IDs in the category: 5
  • Maximum number of IDs in the category: 2000
  • FDR Method: BH
  • Significance Level: FDR < 0.05
